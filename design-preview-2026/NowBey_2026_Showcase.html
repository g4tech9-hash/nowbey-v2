NowBey Design System · v2026.10 · Preview

Tideglass — calm signal for a living island.

A ground-up identity for 2026: dark-first tokens with calibrated contrast, liquid glass reserved for control layers (never the data), bento modularity for glanceable scanning, a ⌘K command palette that augments visible navigation, and a thumb-zone mobile shell synced token-for-token with the web.

Five principles

1 · Signal over noise
Severity is encoded in color, glow and meter — readable in a glance at 3am.
2 · Calm glass
Translucency on navigation and overlays only. Numbers stay on solid surfaces.
3 · Honest states
No dark patterns. Confirmations, “soon” labels and empty states tell the truth.
4 · Thumb-first
Primary actions live in the bottom 20% of the phone; nav is bottom-heavy.
5 · Motion with a job
Every animation communicates state; all of it yields to prefers-reduced-motion.

Global tokens

Color — dark-first, light as a first-class twin

The same custom-property names drive both themes; components never branch on theme. Brand DNA (abyss · tide · conch · sun) is preserved and re-calibrated for OLED blacks and WCAG AA on every text pairing.

Mobile adaptations

  • Bottom tab bar inside the thumb arc; center Report action raised with a tide glow
  • Primary actions bottom 20% — “Pin a spot” sits above the nav, never the top
  • Spring press scale + light haptic on every control (expo-haptics)
  • Bottom sheet with bento tiles — one swipe from map to full list
  • Severity rings pulse only at sev ≥ 4; static everywhere else
  • Reduced-motion setting collapses every animation

Token sync

Remediation · v2026.10-b

Light mode, rebuilt — and the Island Record

The old light mode failed contrast at nearly every text tier. The rebuild keeps the technical character by earning precision from crisp cool off-whites, structural hairlines and a deep teal text tier — "instrument panel on paper" instead of "neon on black". Every text token now passes WCAG AAA on both white and raised surfaces.
